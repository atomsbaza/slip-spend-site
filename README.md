# Slip Spend — site

Static pages for the Slip Spend iPhone app, served with GitHub Pages: landing/support (`index.html`) and the privacy policy (`privacy.html`, Thai + English). Contact is through this repository's Issues. The app itself lives in a separate private repository.

The privacy policy must match what the app does; update it in the same change as any behaviour that touches data (new permission, network use, new extension, analytics).
